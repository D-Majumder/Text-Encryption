# Text-Encryption

A Python demonstration of text encryption and decryption using AES, DES, and RSA.

## Overview

This project demonstrates how to encrypt and decrypt text using three encryption algorithms: AES (Advanced Encryption Standard), DES (Data Encryption Standard), and RSA (Rivest-Shamir-Adleman). It's an educational tool for understanding the implementation and usage of different encryption algorithms in Python.

## Features

- Generate RSA keys
- Encrypt AES and DES keys using an RSA public key
- Decrypt AES and DES keys using an RSA private key
- Encrypt and decrypt a message using AES and DES

## Setup

```bash
git clone https://github.com/D-Majumder/Text-Encryption.git
cd Text-Encryption
pip install pycryptodome
python "Text Encryption.py"
```
